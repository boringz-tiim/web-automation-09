# TPshop 本地登录测试环境

这个页面专门用于练习 Selenium PO 模式，不访问互联网，也不会遇到教学网站的 CSS 限流问题。

## 页面数据

- 登录地址：`http://127.0.0.1:8000/Home/user/login.html`
- 有效账号：`15154251600`
- 有效密码：`123456`
- 万能验证码：`8888`

页面元素与现有 `LoginPage` 保持一致：

- 用户名：`(By.ID, "username")`
- 密码：`(By.ID, "password")`
- 验证码：`(By.ID, "verify_code")`
- 登录按钮：`(By.CSS_SELECTOR, ".J-login-submit")`
- 弹窗文字：`(By.CSS_SELECTOR, ".layui-layer-content")`
- 弹窗确定按钮：`(By.CSS_SELECTOR, ".layui-layer-btn0")`
- 成功结果：`(By.LINK_TEXT, "安全退出")`

## 使用步骤

1. 打开一个 PowerShell 窗口，进入本文件所在目录。

2. 启动本地服务器：

   ```powershell
   python server.py
   ```

3. 保持这个窗口运行，不要关闭。

4. 将练习项目 `config.py` 中的地址临时改成：

   ```python
   LOGIN_URL = "http://127.0.0.1:8000/Home/user/login.html"
   ```

5. 再打开一个 PowerShell 窗口运行测试：

   ```powershell
   cd D:\Pythonproject\09-test
   pytest -s scripts/test_login.py
   ```

6. 练习结束后，在服务器窗口按 `Ctrl+C` 停止。

## 推荐的小修改

`base/base_page.py` 中建议这样写：

```python
def base_click(self, loc):
    self.get_clickable_element(loc).click()

def base_input(self, loc, text):
    element = self.get_element(loc)
    element.clear()
    element.send_keys(text)
```

本地环境不会替换或修改原来的项目；要重新测试线上站点时，只需把 `LOGIN_URL` 改回原地址。
